# 📦 Copper Equipments – Changelog

All notable changes to this project will be documented in this file.

---

## 🧪 Version 1.0.3 – November 8, 2025

### Included in this build:

#### 🧪 Item Oxidation System
Copper-based items now visually oxidize based on durability:

- **100–75%** → Regular Copper
- **74–50%** → Exposed Copper
- **49–25%** → Weathered Copper
- **24–0%** → Oxidized Copper

*Note*:
- This is a dynamic texture system — not separate items.
- Waxing is not supported yet (planned for 1.0.4).

#### 🐛 Bug Fixes
- Minor internal cleanup
- Rebalanced mining efficiency and level
- Copper tools now appear correctly in creative tabs

---

## 🧱 Version 1.0.2 – November 3, 2025

### Included in this build:

#### 🧱 Copper Block Variants
All copper-based blocks now support full oxidation and waxing:

- Copper Lantern → exposed, weathered, oxidized + waxed versions
- Copper Chain → exposed, weathered, oxidized + waxed versions
- Copper Bars → exposed, weathered, oxidized + waxed versions

Each variant follows vanilla oxidation progression and can be waxed to preserve its state.

#### 🐛 Bug Fixes
- Minor internal cleanup
- Improved consistency

---

## ✨ Version 1.0.1 – October 31, 2025

### Included in this build:

#### ✨ Enchantable Equipment
- Copper armor and tools are now enchantable like vanilla gear

#### 🔁 Copper Recycling System
- Smelt copper gear to recover **Copper Nuggets**

#### 🧱 New Copper-Based Blocks
With the addition of Copper Nuggets, new blocks are now craftable:

- 🕯️ Copper Torch: emits warm green light
- 🏮 Copper Lantern: animated, crafted using the torch
- ⛓️ Copper Chain: for hanging blocks or decoration
- 🚧 Copper Bars: fence-like, connectable block
